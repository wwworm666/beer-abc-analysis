# Культура OS 1.1.0

Плагин доступа ко всему MCP-каталогу kultura.os и подробным инструкциям.
Подключение: `https://beerkultura.ru/mcp`, OAuth, активный аккаунт kultura.os.
При авторизации выберите «Полный доступ» для работы со всеми инструментами.

Включает рабочий skill `kultura-os` и проверку подключения `setup`.
Ключи моделей и секреты в пакет не входят. Модель работает на стороне текущего чата.
Полный доступ не запускает действия самостоятельно: изменения и отправка сообщений
выполняются только по запросу пользователя.

Установите через поддерживаемый импорт пакета или каталог репозитория
`.agents/plugins/marketplace.json`, затем подключите MCP и откройте новый чат.
Подробности: `docs/kultura-plugin.md` в репозитории
https://github.com/wwworm666/beer-abc-analysis.
