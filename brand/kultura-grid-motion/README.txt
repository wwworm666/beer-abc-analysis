KULTURA — GRID MOTION

Машинный набор в фиксированных ячейках: kultura группами ku / lt / ura, окончания по одной букве. Только буквы и фирменная оранжевая точка, без отдельного курсора. Одинаковый кегль, без движения готового текста. Завершение знака, названия и звукового акцента синхронно.
IBM Plex Mono Medium. #FF4B0A / чёрный / белый.

Общая заставка: 18,4 секунды.
MP4: 1920×1080, 60 кадров/с, звук.
GIF: 960×540, 25 кадров/с, без звука, бесшовный цикл.
Отдельные анимации: 8 секунд; GIF 512×512, MP4 600×600.

motion/ — готовые файлы.
static/ — утверждённые статические логотипы.
source/ — исходники, контуры шрифта, лицензия, звук и композиция.

Повторный рендер: Node.js, ffmpeg в PATH.
В папке source:
  npm install
  npm run build
  npm run render

grid.cjs — движения и тайминг; sound.cjs — оригинальные звуковые щелчки.
index.html — композиция с одной управляемой GSAP timeline.
