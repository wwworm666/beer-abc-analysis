# Плагин Культура OS

## Что это

Новый пакет `kultura-os` версии 1.0.0 для ChatGPT/Codex: удалённый MCP сервиса
и инструкции работы с ним. Не заменяет установленную «Культуру» 0.1.1 автоматически.
Использует модель текущего чата; ключ ClaudeHub/Anthropic/OpenAI в пакет не нужен.

## Файлы

- `plugins/kultura-os/plugin.json` — portable Agent Plugins manifest и карточка.
- `plugins/kultura-os/mcp.json` — HTTPS Streamable HTTP, OAuth DCR, общий `/mcp`.
- `plugins/kultura-os/skills/setup/SKILL.md` — проверка подключения после установки.
- `plugins/kultura-os/skills/kultura-os/SKILL.md` — рабочий процесс, карта разделов,
  расчёты, изменения, отчёты и обработка ошибок.
- `.agents/plugins/marketplace.json` — каталог плагинов репозитория.
- `core/mcp/tools/common.py` — актуальные инструкции через `common_instructions`.
- `tests/test_kultura_plugin.py` — пакет и полнота/границы инструкций.

## Как работает (с примерами и формулами)

`common_whoami` → `common_instructions(domain="all")` → справочник баров и
документация → инструменты выбранных разделов → ответ или запрошенное действие.
Инструкции всех разрешённых разделов загружаются одним вызовом из текущего реестра;
пакет не содержит копию 255 схем, которая устареет после выкладки сервиса.
На 22.11.2026 общий каталог содержит 255 инструментов, режим чтения — 151.
Точное число проверяется через `common_whoami`, а не служит константой протокола.

Полный адрес — `https://beerkultura.ru/mcp`, без `/read`. В OAuth-согласии нужен
«Полный доступ», активный администратор сайта и все разделы. Старый грант чтения
не повышается автоматически: требуется новое согласие. Ограничения сервера
сохраняются на каждом вызове. Аккаунты, пароли и секреты — сознательные исключения
из MCP, не обходятся плагином. «Все инструменты» не означает все HTTP endpoints.

Подробные формулы остаются в документации модулей через `common_docs_list/read`.
MCP-виджеты внутри чата этот пакет не добавляет. Графики и отчёты сервиса доступны
через существующие инструменты; отправка в Telegram — только по запросу.

Для браузерных запросов разрешены точные Origin `chatgpt.com` и `chat.openai.com`;
посторонние домены и домены-двойники не допускаются.

Сервер возвращает issuer (iss) и разрешает официальный callback
`https://chatgpt.com/connector_platform_oauth_redirect`. Если администратор задавал
свой список хостов OAuth, для подключения в нём нужен `chatgpt.com`.

OAuth обнаруживается по ответу 401 и `WWW-Authenticate`, затем по метаданным
сервера. Поле `extensions` у сервера в `mcp.json` не добавлено: опубликованная
portable JSON-схема 1.0.0 его запрещает, хотя руководство OpenAI показывает
такой пример. Здесь используется валидный portable endpoint и штатный discovery.

### Установка и проверка

Репозиторий содержит каталог для локальной/repo-установки. Подключить репозиторий
как источник плагинов в поддерживаемом клиенте и установить `Культура OS`.
Конкретный способ добавления источника зависит от версии клиента; наличие файлов
в GitHub само по себе не устанавливает плагин в аккаунт.

Для загрузки пакетом архивировать **содержимое** `plugins/kultura-os`, чтобы
`plugin.json` находился в корне ZIP. Если интерфейс поддерживает импорт ZIP,
загрузить архив; иначе использовать поддерживаемый импорт GitHub/marketplace.
Публичная публикация в каталоге OpenAI — отдельный процесс, здесь не выполняется.

После установки войти через OAuth на beerkultura.ru, выбрать полный доступ,
открыть новый чат и вызвать настройку плагина. Проверить whoami (all/full),
получение общих и четырёх разделов инструкций, список документации и один
вопрос о данных. Изменяющий инструмент не вызывать ради проверки.

Источники формата, сверены 22.11.2026:
- https://developers.openai.com/plugins/build/plugins
- https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- https://agent-plugins.org/schemas/1.0.0/mcp.schema.json
