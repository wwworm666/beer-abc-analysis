# ClaudeHub: подготовка единого подключения

## Что это

Запрошен единый ключ `ClaudeHub` и четыре модели: `claude-opus-5-5`,
`gpt-6.1-sol`, `claude-fable-5-2`, `gpt-6-astra`.
Это подготовка перехода; рабочий сервис пока остаётся на прямом OpenAI.

## Файлы

- `kultura_bot/engine/gateway.py` — разрешённый каталог, адреса, отдельный ключ,
  строгий разбор тарифов провайдера и ошибок внутри HTTP 200.
- `engine/claude.py`, `engine/astra.py` — необязательный base_url при создании SDK;
  прежние адреса по умолчанию сохранены.
- `tests/test_kultura_gateway.py` — проверка адресов, секретов и тарифов.

## Как работает

Anthropic endpoint: `https://api.claudehub.fun`.
OpenAI Chat Completions base: `https://api.claudehub.fun/v1`.
Прямые ключи OpenAI и Anthropic не используются для стороннего адреса.
Тарифы берутся из каталога провайдера `/v1/models`, а не из прайса OpenAI/Anthropic.
Неизвестный тариф не считается нулевым; fast ×2 и наценка длинного контекста
не переносятся автоматически. Настройка рабочего подключения ещё не изменена.

### Проверка 17 ноября 2026

- Ключ доступен. Простой текстовый запрос принят для всех четырёх моделей.
- Принудительный обычный вызов `test_echo(value=7)` выполнен Opus, Sol и Astra.
- Fable на принудительный `tool_choice=tool` вернула ошибку внутри HTTP 200;
  при автоматическом выборе в другом тесте вернула корректный `tool_use`.
- Responses Astra: запрос серверного `tool_search` дважды вернул только текст,
  без `tool_search_call`, `tool_search_output` и вызова функции. Это произошло
  и при явном выборе `tool_choice={type: tool_search}`.
- В тесте Anthropic server search Opus сообщила, что наш `test_echo` виден как
  `TodoWrite`, и не вызвала его. Fable упомянула такое же имя, но вернула
  внешний вызов `test_echo`. Равноценность штатного поиска не подтверждена.
- Проверки содержали только искусственные вопросы и функции, без бизнес-данных
  и отправок сообщений. Ответ `/v1/models` без авторизации также успешен, поэтому
  чтение каталога само по себе не проверяет действительность ключа.

Переход нельзя считать простой заменой base_url: необходимо согласовать совместимый
поиск инструментов либо дождаться подтверждённой поддержки штатного поиска провайдером.
Не заменять поиск передачей всех схем или собственным ограничением выдачи без явного решения.
Также требуется проверить реальные параметры reasoning/streaming/вложений/fast,
продолжение после tool result, затем связать общий ключ и выбор четырёх моделей
с настройками сайта, проверить регрессии и только потом выкладывать обе стороны.
