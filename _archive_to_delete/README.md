# Архив на удаление

Сюда складывается код, который выведен из проекта, но ещё не удалён из репозитория:
владелец чистит папку сам, когда сочтёт нужным. Всё содержимое можно удалить целиком
(`git rm -r _archive_to_delete`) — ничего из него не импортируется, не рендерится и не
попадает в Docker-образ (папка исключена в `.dockerignore`).

Правило: файл переезжает сюда с сохранением исходного пути внутри папки
(`core/…`, `templates/…`), а причина переезда записывается в таблицу ниже и в
`docs/CHANGELOG.md`.

| Файл | Переехал | Почему |
|---|---|---|
| `core/abc_analysis.py` | 2026-09-19 | Прежний ABC фасовки на pandas. Заменён `core/packaging_analysis.py`. Внутри — дефекты, исправленные при замене: буква по накопленному «включая позицию» (флагман с долей 90% получал B), нет защиты от нулевой базы. |
| `core/xyz_analysis.py` | 2026-09-19 | Прежний XYZ по календарным ISO-неделям: требовал 2 недели без проверки продаж, позиция с одной продажей получала CV 0% и букву X. Заменён недельными окнами в `core/packaging_analysis.py`. |
| `core/category_analysis.py` | 2026-09-19 | Прежний разбор по категориям: считал фасовки по строкам (бар × фасовка) и завышал на 45%, guard `if not bar_name` молча подменял третью букву маржой. Заменён `core/packaging_analysis.py`. |
| `core/data_processor.py` | 2026-09-19 | Подготовка DataFrame для старого расчёта: `Style` возвращался в `None` и терялся в `groupby(dropna=True)` — 15,3% выручки. Больше никем не используется. |
| `templates/index.html` | 2026-09-19 | Прежняя страница `/packaging`: ссылается на удалённые `/api/analyze`, `/api/categories`, `/api/weekly-chart`; резала категории до 10, печатала одну сводку под четырьмя заголовками баров. Заменена `templates/packaging.html`. |

Разбор дефектов и формулы нового расчёта: `docs/abc-xyz-analysis.md`.
