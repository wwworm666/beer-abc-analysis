Коннекторы

Коннектор — адрес, по которому ИИ-клиент (Claude Code, приложение Claude, расписания Claude) подключается к сервису. Агент работает от вашего имени и видит то же, что вы на сайте. Приложение Claude подключается по адресу коннектора само и спрашивает разрешение на странице входа; Claude Code — по токену ниже.

Режим доступа задаётся концом адреса: /read — только чтение, /draft — чтение и черновики (например, {{ base_url }}/mcp/content/draft), без суффикса — полный доступ. Действует более строгий из режима адреса и режима токена. Для расписаний и агентов, которые читают тексты гостей, — «Только чтение» или «Чтение и черновики»: тогда ни одна «команда», спрятанная в данных, не дотянется до утверждения, отправки и публичных фидов.

Выпустить токен для Claude Code

Токен в режиме «Только чтение» или «Чтение и черновики» не получит больше, даже если подключить его к адресу без суффикса.
