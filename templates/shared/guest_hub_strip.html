{#- Раздел «Гости»: вкладки раздела и полоса «требует внимания». Подключение: {% set hub_active = 'content' %} -- 'content' | 'reviews' | 'guests' {% include 'shared/guest_hub_strip.html' %} На страницах раздела (/content-plan, /reviews) полосу подключает шапка shared/guest_hub_head.html. На /guests она вставлена отдельно, внутри элемента с классом gh-scope: токены цвета (--gh-*) живут на .gh-scope, а body у /guests свой. Счётчики заполняет static/js/guest_hub/common.js (GH.loadAttention) из /api/guest-hub/attention?bar=<общий фильтр бара>. До ответа видны прочерки; при ошибке полоса молча скрывается. «Ошибки отправки» и «Время вышло» показываются, только когда их больше нуля. Определения счётчиков (подсказки data-tip) — из спецификации раздела: reviews_unanswered — отзывы со статусом «без ответа», любая дата; publications_today — размещения с датой сегодня в статусах «утверждено», «на паузе», «вышло»; delivery_errors — размещения со статусом «ошибка отправки», любая дата; overdue — утверждённые размещения, чьи дата и время уже прошли. Фильтр бара X: для отзывов — отзывы бара X; для размещений — бар X и размещения на всю сеть. Ссылки ведут туда, где видно ровно то, что посчитано: «Отзывы без ответа» -> /reviews?status=new&month=all — счётчик берёт отзывы за любую дату, поэтому и список открывается «За всё время» (без month страница показала бы только текущий месяц, и 1-го числа отзывы, ждущие дольше всех, пропали бы из списка); «Публикаций сегодня» -> /content-plan?view=calendar; «Ошибки отправки» / «Время вышло» -> /content-plan?state=failed|overdue — без month контент-план открывает эти состояния по всем месяцам. -#}
