СВОДКА литры — расход кегов со склада по данным iiko
РЕШЕНИЯ ПО АССОРТИМЕНТУ выручка, наценка и число порций за период
Каждый кег ровно в одной группе. Правило группы и её состав открываются кликом по карточке. Решение «вывести» выносится только по периоду от четырёх недель: на пресете «неделя» группа показана, но действие отложено. Продажи считаются порциями, как штуки у фасовки.
КАТЕГОРИИ
Категория — стиль пива. У самого кега стиля в номенклатуре нет: все кеги лежат одной плоской группой, поэтому стиль берётся с блюда-порции, которым кег продаётся (третий уровень дерева, «Хели (Р)»), и при нескольких стилях побеждает тот, на который пришлось больше выручки. Кег без продаж в периоде и блюдо без третьего уровня собраны в «Без категории (Р)» и участвуют в расчёте наравне с остальными. ABC категории — место по выручке среди категорий разреза. Клик по строке открывает карточку со всеми кегами категории.

Наценка — по порогам розлива: 250% — минимальная наценка сети, ниже неё кег с продажами попадает в «Низкую наценку»; 200% — граница между B и C (цена втрое выше себестоимости). Маржа — по третям среди кегов разреза: буква говорит, где кег стоит относительно соседей. Разброс спроса — коэффициент вариации недельных литров по неделям, когда кег стоял на кране. Клик по строке — карточка кега с разбивкой «кто наливал».
БАРМЕНЫ ПО ОБЪЁМУ та же выручка и литры, разрез по людям
Бармен — поле «Авторизовал» в iiko, то есть кто пробил позицию в кассе. Порции умножаются на объём порции из техкарты, затем результат по каждому кегу приводится к факту списания со склада — поэтому суммы совпадают с разрезом по кегам. Клик по строке — карточка бармена.
