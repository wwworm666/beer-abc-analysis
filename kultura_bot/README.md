# Бот @MCPkulturabot

ИИ-помощник владельца сети «Культура» в Telegram. Работает на сервере вместе с сайтом, думает
через Claude API, данные берёт инструментами сайта от имени администратора, который ему пишет.
Подробно — [docs/kultura-bot.md](../docs/kultura-bot.md).

## Где что менять

| Что | Файл |
|---|---|
| Как бот отвечает: тон, формат, правила | `prompts/bot.md` |
| Общие правила агентов и формат их отчёта боту | `prompts/agent.md` |
| Агенты, которым бот поручает большие задачи | `agents/*.md` (один файл — один агент) |
| Модель, усилие, пределы шагов, дневной предел расхода, диалог, графики | `settings.py` |

Правка -> PR -> автодеплой. После выкладки бот читает файлы заново, а идущие диалоги
начинаются с чистого листа с пометкой «Обновились инструкции бота».

Секретов здесь нет и быть не должно: репозиторий публичный. Токен бота, ключ Claude API,
прокси и пауза — на странице «Доступ агентов» (`/admin/mcp`), раздел «Бот @MCPkulturabot».
Там же — кто может писать боту: «Подключить мой Telegram».

## Как добавить агента

Файл `agents/<имя>.md`:

```
---
name: supplies
title: Закупки
domains: stocks
description: Когда поручать задачу этому агенту — бот видит это в своих инструкциях.
---
Правила агента обычным текстом: что он делает, откуда берёт цифры, что ему нельзя.
```

- `name` — латиница, цифры, «_», 2–31 символ; по нему бот поручает задачу (`ask_agent`).
- `domains` — разделы сайта через запятую: `content`, `stocks`, `analytics`, `staff`. Агенту
  видны инструменты этих разделов и общие `common_`, остальные — нет.
- Перед PR: `py -3 -m pytest tests/test_kultura_bot.py` — ошибка в заголовке назовёт файл.

## Остальные файлы

| Файл | Что |
|---|---|
| `service.py` | запуск вместе с сайтом, опрос Telegram, очередь чатов, ответ |
| `agent.py` | разговор с Claude: запрос, шаги с инструментами, пределы, расход |
| `tools.py` | инструменты для Claude: инструменты сайта, график, поручение агенту |
| `config.py` | чтение `prompts/` и `agents/`, сборка системных промптов |
| `credentials.py` | секреты со страницы и их проверка |
| `access.py` | привязка Telegram к администратору сайта |
| `claude.py` | клиент Anthropic, тексты ошибок, цена шага |
| `store.py` | таблицы бота в `mcp.db` |
| `formatting.py` | Markdown -> HTML Telegram |
| `telegram_io.py` | приём и отправка сообщений Telegram |
| `charts/` | графики с кнопкой «Открыть интерактивно» — [docs/tg-miniapp.md](../docs/tg-miniapp.md) |
