# Бот @MCPkulturabot

ИИ-помощник владельца сети «Культура» в Telegram. Думает через Claude API, данные берёт
инструментами сайта по MCP. Работает на **отдельном сервере в Амстердаме**: сайт стоит в
России, где API Anthropic недоступен, и сам к Claude не обращается. Подробно —
[docs/kultura-bot.md](../docs/kultura-bot.md).

## Где что менять

| Что | Файл |
|---|---|
| Как бот отвечает: тон, формат, правила | `prompts/bot.md` |
| Общие правила агентов и формат их отчёта боту | `prompts/agent.md` |
| Агенты, которым бот поручает большие задачи | `agents/*.md` (один файл — один агент) |
| Модель, усилие (сейчас `xhigh`), быстрый режим, пределы шагов, дневной предел расхода, диалог, графики | `settings.py` |

Правка -> PR -> слияние в `main`. Сервер бота сам сверяется с GitHub раз в 2 минуты, забирает
новую версию папки `kultura_bot/` и перезапускается; идущие диалоги начинаются с чистого листа
с пометкой «Обновились инструкции бота». Графики рисует и отправляет сайт — их настройки
действуют после выкладки сайта.

Секретов здесь нет и быть не должно: репозиторий публичный. Токен бота, ключ Claude API и
пауза — на странице «Доступ агентов» (`/admin/mcp`), раздел «Бот @MCPkulturabot»; сервер бота
берёт их у сайта. Там же — кто может писать боту («Подключить мой Telegram») и установка сервера
бота («Команда установки»).

## Как добавить агента

Файл `agents/<имя>.md`:

```
---
name: supplies
title: Закупки
domains: stocks
description: Когда поручать задачу этому агенту — бот видит это в своих инструкциях.
---
Правила агента обычным текстом: что он делает, откуда берёт цифры, что ему нельзя.
```

- `name` — латиница, цифры, «_», 2–31 символ; по нему бот поручает задачу (`ask_agent`).
- `domains` — разделы сайта через запятую: `content`, `stocks`, `analytics`, `staff`. Агенту
  видны инструменты этих разделов и общие `common_`, остальные — нет.
- Перед PR: `py -3 -m pytest tests/test_kultura_bot.py` — ошибка в заголовке назовёт файл.

## Сервер бота

Установка — один раз: на странице «Доступ агентов» кнопка «Команда установки», команду
выполнить на сервере в Амстердаме под root. Дальше:

```
systemctl status kultura-bot            # работает ли
journalctl -u kultura-bot -f            # журнал бота
journalctl -u kultura-bot-update -n 50  # журнал самообновления
```

## Остальные файлы

| Файл | Что |
|---|---|
| `engine/` | **сервер бота** (Амстердам), запуск `python -m kultura_bot`; код сайта не импортирует |
| `engine/service.py` | настройки с сайта, опрос Telegram, очередь чатов, ответ, отчёт сайту |
| `engine/agent.py` | разговор с Claude: запрос, шаги с инструментами, пределы, расход |
| `engine/tools.py` | правила и инструменты с сайта по MCP, график, поручение агенту |
| `engine/config.py` | чтение `prompts/` и `agents/`, сборка системных промптов |
| `engine/site.py` | связь с сайтом: MCP и API бота по ключу сервера |
| `engine/store.py` | своя база: диалоги, вопросы, расход |
| `engine/claude.py` | клиент Anthropic, тексты ошибок, цена шага |
| `engine/formatting.py`, `engine/telegram_io.py` | Markdown -> HTML Telegram; Telegram Bot API |
| `deploy/` | установка (`install.sh`), самообновление (`update.sh`), службы systemd, зависимости |
| `credentials.py` | сайт: секреты со страницы и их проверка |
| `access.py` | сайт: привязка Telegram к администратору сайта |
| `store.py` | сайт: привязки, коды привязки, расход и состояние из отчётов сервера бота |
| `site_api.py` | сайт: ключ сервера бота, команда установки, отчёт, состояние для страницы |
| `charts/` | сайт: графики с кнопкой «Открыть интерактивно» — [docs/tg-miniapp.md](../docs/tg-miniapp.md) |
